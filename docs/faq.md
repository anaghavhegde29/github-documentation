# Frequently Asked Questions (FAQ)

## 1. What is GitHub Pages?

GitHub Pages is a free hosting service that allows users to publish websites directly from a GitHub repository.

## 2. What is Markdown?

Markdown is a lightweight markup language used to format text using simple symbols.

## 3. Why do we use the docs folder?

The `docs` folder stores documentation files that GitHub Pages can publish as a website.

## 4. Can I update my website?

Yes. Edit the Markdown files and commit your changes. GitHub Pages will rebuild the website automatically.

## 5. Is coding required?

No. Basic Markdown knowledge is sufficient to create a documentation website.

## Example

```bash
git add docs/
git commit -m "Update documentation"
git push origin main
```
